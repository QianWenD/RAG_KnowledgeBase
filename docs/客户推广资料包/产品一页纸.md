# RAG知识中心平台产品一页纸

## 一句话介绍

RAG知识中心平台把企业内部资料变成可权限管控、可追溯、可运营的智能问答系统，帮助员工更快找到可信答案。

## 适合谁使用

- 制度、流程、规范资料较多的企业。
- 售后、客服、运营、项目、培训等高频问答场景。
- 希望在内网或私有环境中使用AI能力的组织。
- 对资料权限、审计追踪和回答依据有要求的客户。

## 解决什么问题

- 员工找资料慢，重复咨询多。
- 资料版本混乱，回答口径不统一。
- 普通AI工具无法满足企业权限控制。
- 回答没有引用来源，难以核验。
- 知识库上线后缺少维护和审计能力。

## 核心能力

- 智能问答：用户直接提问，系统基于授权知识范围回答。
- 资料入库：支持企业资料上传、解析、切片和索引。
- 文件管理：支持按文件、来源、入库人员、上传时间查询，支持查看、下载和删除。
- 来源管理：按业务来源管理知识边界，便于分类、授权和下线。
- 权限系统：支持用户、组织、菜单角色和访问范围管理。
- 引用追溯：回答可查看参考依据，便于业务核验。
- 审计日志：关键操作可记录、可查询、可追踪。
- 私有化部署：可在客户指定服务器环境中部署运行。

## 客户收益

- 提升知识查询效率，减少重复沟通。
- 统一业务回答口径，降低误答风险。
- 把文档资料沉淀为可运营的知识资产。
- 保留企业权限边界，避免资料过度暴露。
- 上线后可持续维护、审计和扩展。

## 推荐试点方式

建议选择一个业务部门作为试点：

- 2到3个知识来源。
- 30到50份代表性资料。
- 20到50个真实业务问题。
- 5到20名试点用户。
- 2到4周完成试点验证。

## 交付内容

- 系统部署和基础配置。
- 管理员和试点用户账号配置。
- 资料入库和来源规划指导。
- 权限和角色配置指导。
- 客户演示和使用培训。
- 试点问题跟踪和优化建议。
- 上线部署说明和运维注意事项。

## 建议客户准备

- 服务器或云资源。
- 试点资料和来源分类。
- 用户清单、角色规则和权限边界。
- 真实验收问题清单。
- 客户侧业务负责人和IT负责人。
