# RAG知识中心平台客户推广资料包

本目录用于客户介绍、售前演示、试点推进和系统推广。资料基于当前项目能力整理，默认面向非技术客户、业务负责人、IT负责人和试点部门负责人。

## 文件清单

- `customer-demo-deck.md`：客户讲解PPT稿，可直接转为演示文稿。
- `demo-script.md`：现场演示讲稿，包含15分钟快讲版和30分钟详细版。
- `product-one-pager.md`：产品一页纸，适合发给客户或放到方案首页。
- `pilot-rollout-plan.md`：客户试点落地计划，适合项目启动会使用。
- `sales-faq.md`：客户常见问题与回答口径，适合售前、实施、项目负责人统一话术。
- `promotion-content.md`：官网、公众号、朋友圈、销售私信等推广文案素材。

## 推荐使用方式

1. 首次客户沟通：先发 `product-one-pager.md`，让客户快速理解系统价值。
2. 现场讲解演示：使用 `customer-demo-deck.md` 做主线，配合 `demo-script.md` 讲解。
3. 客户有试点意向：用 `pilot-rollout-plan.md` 明确双方准备事项、周期和验收方式。
4. 客户问安全、准确率、部署、权限：参考 `sales-faq.md` 统一回答。
5. 对外推广：从 `promotion-content.md` 选取合适版本发布。

## 对外核心口径

一句话介绍：

> RAG知识中心平台把企业内部资料变成可权限管控、可追溯、可运营的智能问答系统，帮助员工更快找到可信答案。

建议不要一上来强调“大模型”或“RAG技术”，而是先讲客户痛点：

- 资料分散，员工不知道该去哪里找。
- 文档更新后，问答口径难以及时统一。
- 普通AI工具无法保证企业权限边界。
- 回答没有引用来源，客户不敢直接采用。
- 系统上线后缺少运营、审计和维护闭环。

再讲本系统解决方式：

- 资料入库：将文档、制度、手册、案例、知识资料统一入库。
- 智能问答：员工直接提问，系统基于授权知识回答。
- 引用追溯：回答可查看参考来源，便于核验。
- 权限控制：不同用户、角色、来源范围可以分开管理。
- 运营维护：支持文件管理、来源管理、重建索引、审计日志和部署运维。

## 当前版本说明

当前资料适合用于上线前后的客户介绍和试点沟通。若后续前端页面、菜单名称、权限模型或部署架构有变化，需要同步更新本目录内容。
